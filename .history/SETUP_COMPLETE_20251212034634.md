### Key Concepts to Understand:

#### 1. Headless UI Pattern
```tsx
// Logic is separated from presentation
<HeadlessForm onSubmit={handleSubmit}>
  {({ values, handleChange }) => (
    <YourCustomUI />
  )}
</HeadlessForm>
```

#### 2. Component Layers
- **Headless** = Logic only
- **UI** = Presentation only
- **Feature** = Composition + business logic
- **Pages** = Route handling

#### 3. Import Paths
```tsx
// Use @ aliases for clean imports
import { Button } from "@/components/ui";
import { useDebounce } from "@/hooks";
```

## 🎯 Development Guidelines

### File Naming
- Components: `PascalCase.tsx`
- Hooks: `useCamelCase.ts`
- Utils: `camelCase.ts`
- Types: `camelCase.ts`

### Code Organization
```
Feature/
├── index.ts           # Public API
├── Feature.tsx        # Main component
├── FeatureUI.tsx      # UI layer
├── useFeature.ts      # Business logic
├── types.ts           # TypeScript types
└── api/
    └── service.ts     # API calls
```

### Best Practices
- ✅ Use TypeScript for everything
- ✅ Define interfaces for all props
- ✅ Export through index.ts files
- ✅ Use path aliases (@/)
- ✅ Separate concerns (logic vs UI)
- ✅ Create reusable components
- ✅ Add JSDoc comments for complex logic

## 🚨 Common Patterns

### Form Handling
```tsx
<HeadlessForm<FormData>
  initialValues={{ name: "", email: "" }}
  onSubmit={handleSubmit}
  validate={validateForm}
>
  {({ values, errors, handleChange, handleSubmit }) => (
    <form onSubmit={handleSubmit}>
      <Input
        name="email"
        value={values.email}
        onChange={handleChange}
        error={errors.email}
      />
      <Button type="submit">Submit</Button>
    </form>
  )}
</HeadlessForm>
```

### Table with Data
```tsx
<HeadlessTable
  data={items}
  columns={columns}
  pageSize={10}
  renderRow={(item, columns) => (
    <tr key={item.id}>
      {columns.map(col => (
        <td key={String(col.key)}>
          {col.render ? col.render(item[col.key], item) : item[col.key]}
        </td>
      ))}
    </tr>
  )}
/>
```

### API Integration
```tsx
// In useFeature.ts
import { httpClient } from "@/services/httpClient";

export const useJobListing = () => {
  const [data, setData] = useState([]);
  const [isLoading, setIsLoading] = useState(false);
  
  const fetchJobs = async () => {
    setIsLoading(true);
    try {
      const response = await httpClient.get("/jobs");
      setData(response.data);
    } catch (error) {
      // Handle error
    } finally {
      setIsLoading(false);
    }
  };
  
  return { data, isLoading, fetchJobs };
};
```
